# Kinematische Unbestimmtheit ebener Stabwerke

Lehrprogramm Statik, Prof. F. Böhme

Webanwendung zur Untersuchung ebener Stabwerke mit Polplan (Haupt- und Nebenpole),
kinematischer Kette, Abzählformel n = (r + v) − 3s und PDF-Protokoll.

Die Anwendung besteht aus **einer einzigen Datei** (`index.html`). Es ist kein Build
und kein Server nötig. Nur für das PDF-Protokoll wird die Bibliothek jsPDF von
cdnjs.cloudflare.com geladen (Internetverbindung erforderlich).

## Lokal ausprobieren

`index.html` per Doppelklick im Browser öffnen.

## Veröffentlichen

Siehe die Anleitung im Chat bzw. unten:

1. GitHub: neues Repository anlegen, `index.html` und `README.md` hochladen.
2. Netlify: Repository importieren (Build command leer, Publish directory `.`)
   oder den Ordner direkt auf https://app.netlify.com/drop ziehen.
